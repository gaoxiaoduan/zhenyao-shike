# Use Vue Shell and Phaser Runtime

## Context

镇妖十刻同时包含高频实时战斗和大量低频产品界面。实时战斗需要稳定地更新单位、投射物、碰撞、镜头与战场表现；局外养成、术法选择、设置、图鉴和结算则更适合声明式界面。

如果把 Phaser 的逐帧对象直接暴露给 Vue，或把敌人坐标、投射物等逐帧状态放进 Vue 响应式系统，会扩大两个模块之间的接口，增加性能开销，并使战斗运行时难以独立测试和销毁。

## Decision

使用 Vue 3 作为应用外壳，使用 Composition API、`<script setup lang="ts">` 和 TypeScript 实现产品界面。

使用 Phaser 4 作为实时战斗运行时，独立负责：

- 战场模拟与渲染
- 玩家、敌人、法器、投射物和掉落物
- 碰撞、镜头、特效及逐帧战斗状态

Vue 负责：

- 主界面与局前术法选择
- 境界推进、解锁、图鉴和设置
- 升级三选一、法器进阶确认等暂停决策界面
- 暂停菜单与战斗结算

Phaser 同时绘制持续变化的战斗 HUD，包括生命、倒计时、术法冷却、雷达和首领生命。Vue 的暂停型覆盖界面出现时，Phaser 的模拟、计时器、冷却、投射物和敌人全部暂停。

在 Vue 与 Phaser 之间建立一个窄而有类型的会话接口。Vue 只发送开始历练、暂停、继续、提交选择和销毁会话等粗粒度命令；Phaser 只发布升级待选择、关键 HUD 变化、历练结束等领域事件或节流后的快照。

该接口不得暴露 Phaser 的 `Scene`、`GameObject` 或其他运行时对象。敌人位置、投射物位置和逐帧动画状态不得写入 Vue 响应式状态。

## Consequences

- 战斗模块可以在不挂载完整 Vue 应用的情况下测试其规则与生命周期。
- Vue 界面可以替换布局和样式，而不侵入战斗对象模型。
- 跨模块通信需要显式定义命令、事件、生命周期和节流规则。
- Tailwind CSS 主要服务于 Vue 产品界面，不承担逐帧战斗 HUD 的绘制。
