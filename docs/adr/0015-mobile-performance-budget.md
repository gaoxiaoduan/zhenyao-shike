# Establish a Mobile Performance Budget

## Context

镇妖十刻需要呈现高单位密度、自动攻击、密集投射物和大范围法器效果。若没有明确预算，美术表现、敌人数量、分辨率和特效会在开发后期争夺性能，且不同设备上的自动降级可能意外改变实际难度。

## Decision

首发性能目标为：

- 主流移动设备以每秒六十帧为目标。
- 低性能设备至少保持每秒三十帧可玩。
- 移动端内部渲染分辨率最高约为 `1280 × 720`，设备像素比上限为 `1.5`；产品 UI 仍按 CSS 分辨率保持清晰。
- 首版压力场景以约 120 个普通敌人、250 个玩家投射物和 120 个敌方投射物作为初始预算。
- 灵蕴等高数量掉落物必须合并显示与结算。
- 敌人、投射物、掉落物和高频特效使用对象池，避免战斗过程中频繁创建和销毁对象。

自动画质降级只允许减少粒子、残影、屏幕震动和装饰特效，不得减少敌人、攻击判定、投射物伤害或其他会改变难度的规则。

若设备持续无法达到目标帧率，界面建议启用“流畅模式”，同时允许玩家在设置中手动固定画质档位。

## Consequences

- 性能测试必须覆盖接近预算上限的可重复压力场景，而不能只测试正常开局。
- 战斗逻辑和视觉表现需要分离，才能在不改变难度的情况下调整画质。
- 对象池、空间查询和碰撞筛选属于基础架构，不应等到内容完成后再补。
- 预算是首版起点，必须根据真实设备测试调整，而不是被当作引擎理论上限。
