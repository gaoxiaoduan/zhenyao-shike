# Make Run Results Fast and Informative

## Context

镇妖十刻预期玩家在主线中经历多次失败。结算既要让玩家理解本局发生了什么，也要维持“再试一局”的冲动。过长动画、多层页面或与历练无关的弹窗会切断这一循环。

## Decision

- 致命一击后使用约零点六秒的慢镜与定格，明确显示造成死亡的妖物或伤害来源。
- 单个结算页显示存活时间、击杀数、事件完成、法器构筑、获得灵石、妖丹状态和新纪录。
- 系统可以根据本局数据给出一句针对性提示，例如缺少范围压制或移速不足，但不直接指定唯一正确构筑。
- 结算页的两个主要操作是“再次历练”和“返回洞府”。
- 再次历练沿用当前地图和局前术法，使用新的随机种子，并重新提供开局法器三选一。
- 从死亡到重新控制角色的目标是不超过两次点击、约五秒。
- 结算流程不插入强制广告或与本局无关的弹窗。

## Consequences

- 战斗系统需要记录可解释的最后伤害来源和关键统计。
- 构筑提示必须基于明确规则，并避免把相关性误写成确定原因。
- 重开流程需要复用已选地图与术法，同时彻底销毁上一场 Phaser 会话。
- 里程碑剧情或解锁提示应在核心结算信息之后出现，不能阻塞快速重开。
