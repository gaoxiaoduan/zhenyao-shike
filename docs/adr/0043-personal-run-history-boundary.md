# 历练记录只保存个人可复盘数据

## Context

单独展示统计不能稳定回答玩家“下一局为什么值得重开”。当前切片需要保留失败与胜利的事实，让玩家比较时间、斩妖数、妖王战和构筑，并由这些事实生成单一的“再来一把目标”。首版不需要全球排行榜或社交竞争。

## Decision

- 每局主线历练都记录胜负、历练时间、斩妖数、精英斩妖数、妖王战用时、是否经历妖王的狂月阶段、完成的战场事件、最终法器构筑和失败时的最后伤害来源；失败记录与胜利记录同等保留。
- 首页显示当前个人最佳与单一下一局目标；结算显示本局统计、是否刷新个人最佳、上一目标完成状态和下一目标；完整的最近记录在“历练记录”面板查看。
- 个人最佳只包含最快胜场、最高斩妖和最长坚持。最近记录保留 12 局，超出后淘汰最旧条目，但个人最佳继续保留。
- 记录保存在当前浏览器的版本化本地存储中，并使用现有备份与校验边界；损坏或不可用时明确提示当前会话记录，不伪装成已持久化。
- 妖王演练不写入历练记录、不影响个人最佳、不生成妖丹或主线完成记录；“再来一把目标”从个人记录即时推导，不单独存档、不发放永久战斗数值。

## Consequences

- 历练记录服务于个人复盘和下一局动机，不承担排行榜、可信成绩认证、挑战码或长期养成职责。
- 记录字段保持青石岭当前切片的可解释范围；完整长期事件历史与全球统计需要另开规格和存档模型。
- 任何新增目标都必须能指向玩家已看过的事实，并继续通过首页、结算和记录面板这三个既有入口反馈；如果玩家击败妖王却未经历狂月，下一局优先提示经历该阶段。
