# Deepen the Core Loop Before Adding Content

## Context

青石岭切片已经包含一局、法器升级和妖王的完整路径，但普通妖物共享直线追击行为，升级候选固定，玄光护身诀与周天运转的实际效果偏离领域规则。继续增加法器或妖物数量只会放大这些浅层模板，不能形成“求生—成型—反压制”的核心乐趣。

## Decision

- 本轮保持四件基础法器、三件高阶法器、三种普通妖物和一种精英妖物的切片规模，先让现有内容形成可辨识机制，不扩充内容清单。
- 野猪妖承担厚甲突进职责，缓慢接近并在清晰预警后直线冲撞；木狼承担快速追击职责，尝试从侧面形成包围；雾蛾承担远程职责，保持距离并发射缓慢、清晰可躲的雾弹。
- 首个精英狼标记主角并在约 `0.8` 秒预警后高速扑袭；扑空后进入短暂虚弱窗口。该机制与场内生命条共同提示玩家优先处理精英，并为啸月狼王的移动威胁建立预期。
- 标准力量曲线为：前两分钟以走位求生；中期由法器选择形成构筑方向；获得首件高阶法器后可以稳定压制普通妖物，但精英妖物和妖王仍要求主动走位。
- 妖潮以 `0:00`、`2:30`、`5:30`、`8:00` 为阶段边界，逐步加入新的妖物职责、职责组合波次和短暂密度峰值；不使用单一固定间隔或根据玩家表现暗中调难。
- 升级候选使用可复现的种子随机且同轮不重复；条件允许时尽量同时提供已持有法器强化、新法器和弹性候选。已持有且可升级的法器连续三次未出现时触发保底，推演不立即重复刚放弃的三张卡。
- 弹性候选使用不占法器槽的“临战机缘”：砺锋使全法器伤害增加 `3%`，周流使攻击间隔减少 `3%`，固元使最大生命增加 `4%` 并回复等量生命；各最多参悟三次。它们用于在不扩充法器清单的前提下维持真实三选一与推演候选空间，不替代法器满阶后的周天运转。
- 玄光护身诀使用约十秒冷却，提供约 `1.5` 秒护盾并震退附近妖物，不承担主要伤害；释放术法不改变仍被玩家保持的移动意图。
- 瞬时术法和自动出现的升级选择保留玩家真实保持的移动按键状态，选卡后若方向键仍按下则继续移动；手动暂停、打开设置、窗口失焦或页面隐藏会清空移动输入。
- 周天运转遵守 ADR-0001：御器使法器伤害增加 `6%`，行气使攻击间隔减少 `5%`，炼体使最大生命增加 `8%` 并回复等量生命；所有已展示效果必须真实进入战斗结算。
- 高密度战斗不常驻显示普通伤害数字。打击感由受击闪白、轻微击退、击杀碎散、精英生命反馈和分层音效共同表达。

借鉴其他幸存者类作品只限于走位、自动攻击、拾取成长、三选一构筑和力量跃迁等通用体验原则；名称、世界、法器、妖物、美术、音频和具体机制继续遵守原创约束。

## Acceptance Targets

- 首次升级出现在约 `20–30` 秒；十分钟成长阶段提供约 `14–17` 次升级选择；合理构筑在约 `6:30–8:00` 取得首件高阶法器。
- 普通妖物活跃数量按妖潮阶段从约 `12–18`、`30–45`、`50–70` 增长至 `75–90`，规则硬上限为 `100`；`120` 只普通妖物只作为独立压力测试预算。
- 第一只精英妖物约在 `1:45–2:15` 出现，之后约每 `75–90` 秒提供一次精英压力；八分钟后最多允许两只精英妖物同时存在。
- 标准难度的初次游玩目标为约半数玩家进入妖王战、约 `25%–35%` 首次击败妖王；理解构筑后的目标胜率为约 `65%–80%`。这是平衡与试玩目标，不用于隐藏动态难度。
- 视野、锁敌窗口、战场雷达、输入连续性、精英生命条、妖物职责、升级随机和妖潮节奏作为一个相互平衡的整体交付，不能只放大视野而保留旧生成与锁敌规则。
- 固定种子规则测试覆盖升级随机与保底、妖潮阶段、职责规则、周天效果、战斗视野和锁敌窗口；Vue 组件与三浏览器 E2E 覆盖 `1/2/3` 选卡、移动中施法、选卡后连续移动、战场雷达和精英生命反馈。

## Consequences

- 妖物运行态需要显式职责和机制状态，不能继续通过敌人 ID 字符串在单一追击循环中零散特判。
- 升级随机、保底、周天效果和妖潮阶段属于可复现领域规则，应从 Phaser 场景中抽离并使用固定种子测试。
- 内容扩展以前必须先证明至少三种现有构筑能够完成从早期求生到后期反压制的完整一局。
