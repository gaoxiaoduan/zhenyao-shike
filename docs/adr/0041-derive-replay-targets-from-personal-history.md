# 从个人历练记录生成单一再来一把目标

## Context

青石岭已经能保存个人历练记录，但单独展示统计不能稳定回答“下一局为什么值得重开”。再来一把目标需要使用玩家已经看过的时间、击杀、事件和法器构筑，同时不能变成每日任务、永久战斗数值或额外的局外养成系统。

## Decision

- 目标不单独存档，而是从当前浏览器中的个人历练记录和个人最佳即时推导；记录删除或损坏时回到首局生存目标。
- 首页在开始历练前展示当前目标，结算页同时保留上一局目标的完成/未完成反馈和下一局目标。目标只提供建议，不阻止玩家再次历练，也不发放额外奖励。
- 首版每次只展示一个确定性目标，不增加目标选择器、每日刷新或放弃按钮；玩家可以直接再次历练，未完成时以“继续”反馈，后续试玩再决定是否需要多目标选择。
- 目标优先鼓励可解释的下一步：短局失败推进最长坚持时间；到达妖王战后补个人历史中尚未完成的战场事件并引导击败妖王；连续重复构筑时提示更换一件法器；胜利后根据击杀个人最佳或可达的最快胜场继续挑战。
- “历练时间”包含成长阶段和妖王战，妖王战用时仍作为独立指标显示。这样速通目标与玩家看到的结算时间使用同一事实来源。

## Consequences

- 目标生成与完成判断保持在纯领域模块中，Vue 只负责展示，Phaser 只负责发布完整的历练结算。
- 目标不会污染灵石、妖丹、境界或法器数值，也不引入全球排行榜、社交竞争、挑战码或可信成绩认证。
- 目标组合仍需要通过首次玩家试玩验证；如果单一目标不能形成“再来一把”动机，下一轮再增加可选目标，而不是提前扩展长期系统。
