# 以构筑驱动战斗爽感

游戏采用俯视角移动表现，但核心战斗体验选择以法器构筑成型后的清屏压制感为主，以走位求生为辅。玩家应主要因为理解并组合了法器而从受困转为压制妖群；走位负责维持风险，妖王负责制造紧张峰值。术法在局外学习、局前选择并于局内固定，法器则由玩家在局内持续选择、升级与组合，两者不能混成同一个成长池。我们不采用手动瞄准主导的操作模型，因为它会增加移动端输入负担，并与自动攻击及局内构筑争夺体验重心。

## Consequences

- 法器之间必须形成清晰、可预期的协同关系，并在成型后产生显著的视听与战力跃迁。
- 局内升级必须持续提供有意义的法器选择，不能自动替玩家决定构筑；随机结果也不能让合理选择失去成立机会。
- 每件基础法器沿五级线性路线成长，满级后才进入合成候选，避免升级分支把首发内容和数值平衡扩张到不可控。
- 主角不受剑修、符修或阵修等固定职业限制；修行流派由本局法器构筑自然形成，允许跨流派组合。
- 进入战场后先暂停并提供三件随机 Lv.1 基础法器，玩家选择第一件法器后才启动刷怪、局内计时与战斗模拟。
- 三选一升级期间完全暂停战斗模拟，包括妖物、弹道、局内倒计时与术法冷却；构筑选择不考验玩家的阅读和点击速度。
- 每局默认拥有一次推演，战场事件最多再提供两次；推演后的候选不能立即重复被放弃的三张卡，且推演次数不能用灵石购买或永久增加。
- 玩家可用吐纳放弃整次升级并恢复百分之十五最大生命值；吐纳不提供其他成长、不返还灵蕴，也不消耗推演次数。
- 主角生命是会在一局中积累损耗的有限资源，不提供常驻自动恢复，也不让普通妖物随机掉落恢复物。稳定恢复来自牺牲成长机会的吐纳，以及玩家主动前往并完成引导的灵泉涌现；每局至少提供一次灵泉涌现机会。
- 不存在任何可获得、可升级或可升阶的法器后，灵蕴升级转为周天运转：御器使法器伤害增加百分之六，行气使攻击间隔减少百分之五，炼体使最大生命增加百分之八并恢复等量生命；每项最多选择三次。
- 敌群密度和压力曲线需要让玩家经历“求生—成型—反压制”，不能从开局起便无脑清屏。
- 走位和主动技能用于创造险境中的决策空间，但不应盖过法器构筑。
