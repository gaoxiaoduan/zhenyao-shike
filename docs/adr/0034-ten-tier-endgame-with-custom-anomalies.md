# Use Ten Endgame Tiers With Custom Anomalies

## Context

突破元婴需要完整结束六至八小时主线，同时为已经掌握构筑的玩家保留长期挑战。如果无相妖域继续提供无限永久属性，主线终点会失去意义，并重新制造数值刷取。

## Decision

- 突破元婴后依次开放无相一阶至无相十阶。
- 每一阶增加公开的规则异变，例如更快妖潮、双精英、危险地形扩散、首领招式组合或降低拾取范围；难度不能只靠提高生命和伤害。
- 每阶仍是一场约十二分钟的完整构筑历练，重组前三张战场的骨架、事件、妖物和妖王规则。
- 完成十阶解锁称号、主角配色、法器特效色和镇妖录条目，不提供永久战斗数值。
- 完成十阶后开放自定义异变和随机种子挑战码，玩家可以分享并复现同一内容组合。
- 自定义挑战不产出主线妖丹，也不接入可信排行榜。

## Consequences

- 异变必须使用可组合的规则模块，并在开始前清楚展示影响。
- 挑战码需要包含内容版本；版本不兼容时必须明确提示，不能悄悄生成不同战场。
- 外观奖励需要与标准主角和法器动画共享资产结构，避免为每阶复制完整动画集。
- 元婴结局保持完整，无相妖域是余波与精通挑战，不是延迟真正结局。
