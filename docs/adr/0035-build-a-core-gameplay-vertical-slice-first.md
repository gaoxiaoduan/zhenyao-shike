# Build a Core Gameplay Vertical Slice First

## Context

完整首发包含三张主线战场、十个境界节点、十八场必要胜利、PWA、洞府、剧情与无相妖域。如果先横向铺开全部内容，移动手感、自动攻击、升级构筑和从受困到清场的核心体验会太晚得到验证。

## Decision

第一个可玩版本只制作一条完整的青石岭核心玩法切片：

- 一张固定骨架、随机内容的连续正方形青石岭战场。
- 约十分钟成长阶段与啸月狼王妖王战。
- 青锋剑匣、雷篆符册、四象阵旗和扶摇羽衣四件基础法器。
- 诛邪剑阵、流光剑翼和九霄雷阵三个高阶组合。
- 默认术法玄光护身诀。
- 三类普通妖物、一类精英和一名妖王。
- 一个战场事件。
- 移动触控与键盘控制、升级三选一、推演、吐纳、法器进阶、HUD、暂停和结算。
- 使用可替换的原创占位美术，先验证玩法而不是等待完整美术资产。

切片暂不制作完整洞府、十境界主线、三张地图、PWA 离线和匿名统计，但已确认的接口必须为这些能力保留 seam。

切片进入内容扩展前必须满足：

- 新玩家在一分钟内理解移动、自动攻击、拾取灵蕴和升级。
- 至少三种构筑可以完成整局。
- 移动端压力场景达到已确定的性能预算。
- 从前期受困到后期反压制的强度变化清晰可感。

## Consequences

- 第一阶段优先完成可玩的纵向链路，而不是大量菜单和内容清单。
- 占位资产必须通过稳定内容 ID 引用，以便后续直接替换。
- 首个妖王、法器和敌人实现将成为后续内容的模块样板，需要保持接口清晰。
- PWA、Cloudflare 统计和完整养成只保留 seam，不在切片阶段提前实现空壳功能。
