# Use Three Purposeful Hub NPCs

## Context

单主角结构仍需要人与人的关系来承载凡人生活、修行知识和外部世界，但过多常驻角色会增加立绘、对话和系统入口，也容易把洞府变成每日任务中心。

## Decision

首发使用三名常驻 NPC，每人同时承担一个系统职责和一种叙事视角：

1. 凡人药师。青石岭幸存者，连接陈砺安与普通生活，讲述伤亡、家园和修行目的；不负责出售永久属性。
2. 落魄阵修。掌握残缺的镇妖盘与古封印知识，连接法器、配方和封印线索；他是互相合作的散修，不是传功老祖。
3. 行脚探子。往返三地并带回妖潮、事件与妖王情报，连接镇妖录和新战场提示，同时提供较轻松的人情味。

不制作每日任务、好感度刷取、送礼或首发恋爱线。NPC 可以因固定剧情受伤或暂时离开，但系统功能不得因随机永久死亡而锁定。

具体姓名与台词属于可迭代内容，不在此决策中固定。

## Consequences

- 每个 NPC 的对话必须推进角色关系、世界信息或系统理解，不能只是重复按钮说明。
- 系统功能需要在 NPC 暂离剧情中保留直接入口。
- 三人分别代表凡人生活、修行知识和外部情报，可以从不同立场回应陈砺安的境界变化。
- 新 NPC 只有在提供新的长期关系或深模块时才加入，不能因单个按钮新增常驻角色。
