# Launch Free With Organic Sharing

## Context

首发采用无账号、本地存档和 Cloudflare 静态部署。广告复活、付费数值、抽卡或邀请奖励都会改变死亡、灵石经济、隐私范围和服务端需求，也会干扰对核心构筑乐趣的验证。

游戏仍需要低摩擦的自然传播入口，让玩家可以把镇妖十刻分享给朋友。

## Decision

首发版本完全免费，不接入商业化系统：

- 不接广告 SDK，不提供广告复活。
- 不出售灵石、妖丹、法器强度或随机抽取内容。
- 不让付费内容影响战斗数值或境界推进。

首发提供分享链接按钮，作为产品的正式传播入口。分享不绑定邀请人身份，不提供拉新资源奖励，也不要求账号或服务端归因。

- 洞府主界面常驻“分享游戏”，分享简短介绍和游戏官网链接。
- 结算页提供“分享战绩”，文案可以包含境界、存活时间、击败的妖王和代表性法器。
- 移动端优先调用系统分享能力；不可用或调用失败时复制文案与链接，并显示明确反馈。
- 分享链接只指向游戏入口，可以携带匿名 `from=share` 来源参数，不包含存档或玩家标识。
- 不自动弹出分享，不通过资源奖励强迫分享。
- 首发不生成复杂战绩海报；后续根据实际传播效果再决定是否加入图片卡片。

如未来考虑一次性支持包、原声、美术集或纯外观内容，必须另行作出决策，并保持战斗数值独立。

## Consequences

- 首发可以专注验证留存、构筑爽感和完整主线，不需要广告、支付和服务端反作弊。
- 分享能力必须兼容移动端和桌面浏览器，并提供系统分享不可用时的降级路径。
- 首发传播数据只能使用匿名聚合方式衡量，不能识别邀请关系。
- 动态战绩文案必须能在缺少某项数据时自然降级，不能因分享失败阻塞结算或重开。
