# 以单主角承载长期修行

首发版本只设置一位持续成长的原创男性主角，每一局都是他的修行经历，所有境界进度均积累在他身上；其他修士作为 NPC 存在，不建立可玩角色收集阵容。主角身份、出身、形象和剧情固定，默认姓名为“陈砺安”；玩家可以把显示名改为最长六个字，但这不会创建不同角色或改变剧情身份。这个选择优先保证从散修成长至元婴的叙事连续性，同时控制首发所需的角色美术、剧情和技能规模。

## Consequences

- 局间差异和重复游玩价值不能依赖更换角色，需要由法器构筑、战场随机内容及其他局前选择承担。
- 主动技能不再以不同可玩角色作为变化来源，其长期归属需要单独设计。
- 后续若加入新的可玩角色，必须重新处理境界进度、剧情视角和角色专属内容，不能只把 NPC 直接改为可玩单位。
- 自定义显示名只属于本地存档，不改变主角的角色设定、称谓逻辑、动画或能力。
- 自定义显示名去除首尾空格后必须包含一至六个可见字符，允许简繁中文、英文字母和数字；不允许换行、控制字符、HTML 符号、纯空白或 emoji。无效姓名回退为“陈砺安”。
- 自定义显示名不上传匿名统计，也不进入系统自动生成的分享文案；分享文案使用“我”或“这名散修”等固定称谓。
