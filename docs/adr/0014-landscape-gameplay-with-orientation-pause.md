# Require Landscape for Gameplay With an Orientation Pause

## Context

镇妖十刻以移动端横屏为产品基准，但移动浏览器对强制横屏和全屏 API 的支持并不一致。设备旋转还会改变安全区、画布尺寸和触控位置；若战斗继续运行，玩家可能在布局重排时受到无法控制的伤害。

## Decision

主菜单允许在竖屏下浏览，进入历练必须使用横屏。

战斗中设备转为竖屏时：

- 立即完整暂停 Phaser 模拟、计时器、冷却、敌人和投射物。
- 显示“请旋转设备”的 Vue 遮罩。
- 恢复横屏后仍保持暂停，由玩家主动点击继续。

系统只在玩家点击“开始历练”等明确手势后请求全屏。全屏请求失败时仍允许继续横屏游玩，不把全屏或 Screen Orientation 锁定作为运行前提。

Vue 布局、Phaser HUD 和触控热区必须适配 CSS `safe-area`，避免被刘海、圆角和浏览器工具栏遮挡。

## Consequences

- 竖屏主菜单仍可用于查看进度和设置，但不能开始或继续实时战斗。
- 游戏需要统一处理方向变化、画布缩放、暂停原因叠加和触控取消。
- 从竖屏恢复横屏不会自动继续，减少误触和突然受伤。
- 浏览器是否真正进入全屏不会改变玩法规则。
