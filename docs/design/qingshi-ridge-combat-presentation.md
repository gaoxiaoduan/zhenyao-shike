# 青石岭战斗表现样板

## 目标

把青石岭当前切片从“静态角色图 + 通用程序图形”提升为可读、可记忆、可扩展的战斗表现样板。样板只覆盖当前已经进入运行时的内容，不提前为词汇表中尚未实现的法器、术法或妖物制作最终素材。

## 视觉总原则

- 战斗可读性优先于持续炫技；轮廓、动作、形状和时序不能依赖颜色单独成立。
- 所有角色采用一套三分之四视角动画，通过水平翻转表达左右方向；不制作完整四方向或八方向动画。
- 普通妖物和精英妖物使用统一的职责动作结构：接近、蓄力、攻击、恢复、死亡。
- 妖王保持连续战场，通过登场、阶段、招式、破绽和结束表现形成决战节奏。
- 角色与攻击身份使用逐帧像素素材；危险边界使用程序绘制；命中、死亡、尘土和破绽使用可复用特效。
- 减少动态效果模式保留规则信息，关闭强震、快速闪白、强烈缩放和大部分残影。

## 动画预算

- 普通妖物移动循环：4–6 帧。
- 普通妖物蓄力、攻击、恢复：每段 2–4 个关键姿态。
- 精英妖物扑袭：6–10 帧。
- 妖王招式和阶段动作：8–12 个关键帧，不要求完整方向覆盖。
- 普通受击闪白：不超过 80ms。
- 普通死亡反馈：约 200–300ms，不直接凭空消失。
- 妖王重击震动：低幅度，约 100–140ms，并受减少动态效果设置控制。

## 啸月狼王阶段

### 降临与普通阶段

月影从地面聚合，狼王以白灰毛色、紫色月纹和残缺月环建立身份。冲撞预警使用方向形状，月啸使用带安全缺口的扇形波纹。

### 狂月阶段

狼王生命进入既定阶段后，鬃毛竖起，月纹裂开，影子分裂，眼睛转为赤紫。连续折返突袭需要让玩家看见方向反转；月影数量增加但仍使用独立黑紫剪影。

### 妖王破绽

成功规避关键招式后，狼王胸口或额心的月纹打开，身体短暂失去平衡，破绽轮廓和增伤窗口保持清晰，不使用锁血或强制无敌转场。

## 固定验收场景

使用固定种子和固定构筑进行对照验收：

1. `0:30`：单种普通妖物，检查移动与职责辨识。
2. `2:00`：野猪妖、木狼、雾蛾混合，检查职责动作和预警。
3. `4:00`：精英妖物出现，检查优先级、扑袭和扑空破绽。
4. `8:30`：高密度妖潮，检查法器视觉签名是否互相干扰。
5. 妖王战：检查降临、月影、狂月、破绽和死亡反馈。
6. 以上场景开启减少动态效果，确认危险范围、阶段状态和命中结果仍然明确。
