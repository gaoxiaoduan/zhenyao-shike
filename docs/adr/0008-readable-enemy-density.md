# 以有限职责保持高密度战斗可读

每张主线战场设计五种普通妖物与两种精英妖物，普通妖物分别承担追击、厚甲、远程、突进和辅助职责；任意时刻最多同时生成三种普通妖物。三张战场可以复用行为骨架，但必须通过外形、速度、攻击节奏和至少一个特色能力形成区别。这个限制让战斗保持高单位密度，同时保证移动端玩家能够辨认当前威胁。

## Consequences

- 刷怪编排按职责组合而不是从全部敌人中无约束随机抽取。
- 远程与突进攻击必须具有清晰预警，辅助型妖物必须容易从妖群中辨认。
- 远程普通妖物使用有限攻击席位并遵守屏内敌方投射物安全预算；未取得攻击席位的远程妖物继续游走换位，不能因为场上数量增长而全部同时开火。
- 每种精英妖物由策划固定一个核心机制和对应的轮廓、颜色、音效提示；随机系统只决定其出现位置与时机，不叠加随机能力词缀。
- 新增妖物前应先判断它是否提供新的战斗职责，不能只为增加图鉴数量制作换皮单位。
