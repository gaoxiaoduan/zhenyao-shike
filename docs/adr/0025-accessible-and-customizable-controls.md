# Provide Accessible and Customizable Controls

## Context

镇妖十刻以移动横屏为基准，并包含高密度特效、颜色预警、快速走位和单手拇指操作。固定左右布局、只依赖颜色的危险提示或不可关闭的镜头效果会直接影响一部分玩家的可玩性。此类能力若在 UI 和特效完成后补做，通常需要返工输入、HUD 与表现系统。

## Decision

首发提供以下无障碍与操作选项：

- 移动端可以镜像左右手布局，交换摇杆与术法按钮的位置。
- 玩家可以调整摇杆尺寸、术法按钮尺寸和控件透明度。
- 桌面端可以重新绑定移动、术法和暂停按键，同时保留 `WASD`、方向键、`Space`、`E` 和 `Esc` 默认映射。
- “减少动态效果”关闭镜头前视、屏幕震动、强闪光和大部分残影。
- 敌人与首领危险预警同时使用颜色、轮廓、地面形状和时间变化，不只依靠红绿差异。
- 字号提供标准和大号两档，长文本不在实时战斗中滚动出现。
- 关键事件同时提供视觉和音效提示，静音玩家仍能理解机制。
- 低生命状态不使用持续全屏闪烁。

## Consequences

- HUD 和触控布局必须由配置驱动，不能把左右位置写死在场景中。
- 输入绑定需要冲突检测、恢复默认值和跨版本迁移。
- 每种危险机制必须在静音、减少动态效果和不同色觉条件下验收。
- 视觉特效系统需要把规则反馈与装饰效果分开，以便安全关闭后者。
