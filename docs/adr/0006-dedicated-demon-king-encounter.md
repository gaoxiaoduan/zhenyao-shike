# 让妖王拥有独立决战阶段

生存与成长阶段结束后停止普通妖群生成，并用约三秒的天地异变与危险预警进入妖王战；场上残余普通妖物被妖王吞噬或召回。妖王战只生成该妖王专属设计的少量召唤物，不继续叠加普通无限妖潮，也不设置硬倒计时，目标战斗时长为九十至一百二十秒。这个选择以清晰预警、可读走位、决战难度和胜利成就感优先于全程不断流的敌群压力。

## Consequences

- 每名妖王需要专属召唤物、招式节奏和转场表现，不能只是拥有高生命值的普通敌人。
- 三张主线战场各设计两名妖王，共六名；妖王随境界节点逐步解锁新招式，试炼版本必须拥有完整第二阶段，不能只提高生命与伤害。
- 妖王时长以合理成型构筑为基准：一件高阶法器配合两件中等基础法器时目标为九十至一百二十秒，优化良好的强势构筑可缩短至七十至九十秒，未成型构筑则可能超过一百二十秒并承担更高死亡风险。
- 妖王使用固定属性与真实的多阶段招式进行平衡，不使用锁血、强制无敌时间、根据玩家输出动态减伤或其他暗中抹平构筑差异的手段；强势构筑应当更快，但平衡目标需要让其仍实际面对第二阶段威胁。
- 妖王经过预警的重击必须可以通过观察和移动完全规避，不使用周期性全场强制扣血维持压力。成功避开冲撞或月影突袭后，妖王暴露约 `1.5–2` 秒破绽并承受约 `25%` 额外伤害，使战斗时长来自攻守转换而不是单纯增加生命。
- 啸月狼王第一阶段使用追猎、预警冲撞和召集月影；生命降至约 `55%` 后直接进入狂月阶段，加入连续折返冲撞、带落点预警的月影突袭和狼群包围。月啸表现为带安全缺口的可规避扩散波，不直接结算全场伤害。
- 啸月狼王第一阶段每次召出两只月影，狂月阶段每次三只；场上最多同时存在八只，超时月影自行消散，新召唤不得突破上限。
- 主线妖王战失败仍结束整局并要求重新构筑，不能在同一局直接续战。首次抵达某名妖王后，在洞府解锁无奖励的妖王演练；演练不产出妖丹、灵石或主线完成记录。
- 妖王战在屏幕顶部使用专属生命条，显示妖王名称、当前阶段、狂月阈值和破绽状态，并提供受击、转阶段与濒死反馈；场内小生命条只辅助空间定位，不显示精确生命数字。
- 首发妖王为青石岭的啸月狼王、盘根槐母，沉星泽的吞雾蟾君、玄鳞泽蛟，以及烬沙古战场的烬羽沙鸮、万兵妖主；万兵妖主承担元婴破境终战。
- 妖王转场时，战场上所有未拾取灵蕴自动飞向主角；由此触发的升级选择和升阶在完全暂停状态下依次结算，全部完成后妖王才开始行动。
- 残余妖物、弹道与其他掉落物必须按明确规则结算，避免转场制造不透明损失。
- 妖王战的胜负由击杀或主角死亡决定，战斗时长是调优目标而非强制计时规则。
