# Launch in Simplified Chinese With Localization Keys

## Context

镇妖十刻依赖大量修仙术语、法器说明、敌人名称和动态分享文案。首发同时制作多语言会分散内容校对与字体预算，但把中文硬编码进组件、Phaser 场景和内容配置会使未来翻译代价显著增加。

## Decision

- 首发只正式支持简体中文，不展示尚无完整译文的语言选择器。
- Vue 文案、法器和妖物名称、描述、战斗短文本与分享文案统一通过语言键获取。
- 内容定义保存 `nameKey`、`descriptionKey` 等稳定键，不保存面向玩家的最终字符串。
- Vue 与 Phaser 使用同一语言服务和同一术语来源。
- 后续本地化优先考虑繁体中文，再根据海外访问与反馈决定英文。
- 中文字体按实际使用字符制作子集，并在构建或内容校验中检查生僻修仙术语缺字。

## Consequences

- 即使首发只有一种语言，新增内容也必须先注册语言键。
- 动态数值、按键名称和分享文本需要使用可组合的格式化模板，不能靠字符串拼接假设中文语序。
- 字体子集需要随内容更新自动重建或校验。
- 术语表必须作为产品、策划和代码共享的唯一来源。
