# Embed Onboarding in the First Run

## Context

镇妖十刻的基础操作简单，但玩家需要快速理解移动走位、自动攻击、拾取灵蕴、术法释放和法器持续升级。如果先要求完成独立教程，玩家会在体验真实构筑和妖群压力之前多经历一次进入与退出流程。

## Decision

不制作独立教程关。教学嵌入玩家第一次进入青石岭的正式历练，并在前四十五至六十秒降低敌群压力。

- 首次开局固定提供 `青锋剑匣`、`雷篆符册` 和 `扶摇羽衣`。
- 教学依次引导移动、观察自动攻击、拾取灵蕴和释放术法。
- 第一次升级保证出现当前已选法器的升级项，并解释已获得的法器会持续出现在后续成长选项中。
- 必要教学提示出现时完整暂停游戏；完成对应操作后不再重复。
- 玩家可以跳过教学。跳过后立即恢复正常随机候选和敌群压力。
- 世界观只通过简短任务和场景细节引入，不在开局播放长篇设定说明。

## Consequences

- 玩家第一分钟就在累积正式进度，不需要重复打一场无收益教学。
- 首局体验不是完全随机，需要把教程状态与普通开局逻辑分离。
- 教学中断后恢复时必须记住已完成步骤，不能重复阻断玩家。
- 后续新系统应优先使用首次出现时的短提示，而不是扩展成集中式说明关卡。
