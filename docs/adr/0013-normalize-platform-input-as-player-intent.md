# Normalize Platform Input as Player Intent

## Context

镇妖十刻以移动端横屏为产品基准，同时必须支持桌面浏览器。若战斗规则直接读取触摸事件、键码或鼠标状态，不同平台会形成多套控制逻辑，也会增加未来增加手柄支持的成本。

## Decision

移动端使用单摇杆加单术法按钮：

- 屏幕左侧约百分之四十五的区域按下时生成浮动摇杆。
- 手指滑出摇杆外圈后仍持续追踪，直到触摸结束或取消。
- 右下方提供一个适合拇指操作的大型术法按钮。

桌面端使用：

- `WASD` 移动。
- `↑`、`↓`、`←`、`→` 方向键与 `WASD` 完全等价。
- `Space` 或 `E` 释放术法。
- `Esc` 暂停。
- 鼠标只用于菜单、暂停界面和升级选择，不提供点击移动或手动瞄准。

各平台输入适配器统一输出 `InputIntent`，只包含移动方向、释放术法和暂停等玩家意图。战斗规则不得读取具体键盘、指针或触摸事件。

首发不承诺手柄支持，但手柄可以在未来作为新的输入适配器加入，不改变战斗规则。

## Consequences

- 移动端和桌面端共享同一套移动、术法与平衡规则。
- 输入映射可以单独测试和调整。
- 同时按下相反方向时需要在适配器中归一化为稳定结果。
- 浏览器默认快捷键、页面滚动和触摸手势需要在游戏区域内按需阻止。
