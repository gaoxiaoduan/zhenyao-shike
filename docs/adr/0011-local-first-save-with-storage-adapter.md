# Use Local-First Save With a Storage Adapter

## Context

镇妖十刻首发同时支持移动端和桌面浏览器。账号、跨设备同步和全球排行榜会引入身份认证、隐私合规、服务端数据、反作弊与运营成本，也会增加首次进入游戏的阻力。

局外境界、灵石和内容解锁仍然需要可靠持久化，并且未来可能接入云存档。

## Decision

首发版本无需登录，玩家打开游戏即可开始历练。

以下长期进度保存在本地：

- 境界和镇妖刻印
- 灵石、妖丹与已完成的试炼
- 已解锁法器、术法和进阶配方
- 设置、图鉴与本地统计

首发不提供账号、跨设备同步和全球排行榜。提供存档导出与导入，以降低浏览器数据被清理造成的损失。

领域逻辑通过窄而有类型的 `SaveRepository` 接口读写存档，不直接依赖浏览器存储 API。浏览器存储实现是该接口的首发适配器；未来的 Cloudflare 云存档实现可以替换或组合该适配器，而不改变养成规则。

Cloudflare 首期承担游戏静态资源的部署与分发，并可提供不保存业务状态的匿名统计端点；不提供账号、云存档或其他业务后端。

## Consequences

- 玩家没有注册门槛，首发系统和合规范围更小。
- 清理浏览器数据或更换设备不会自动恢复进度，需要玩家自行导入备份。
- 客户端存档可以被修改，因此首发统计不能被当作可信竞技成绩。
- 存档需要版本号、迁移机制、校验和损坏恢复策略。
- 局内断点恢复策略仍需单独确定。
