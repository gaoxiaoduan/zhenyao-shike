# 使用有边界的正方形连续战场

> 部分修订：ADR-0037 将原有“小型雷达不显示普通妖物”的约束替换为完整战场雷达；普通妖物与灵蕴采用聚合信息，精英妖物、妖王和事件仍使用精确标记。

每一局都在一张有边界的正方形连续战场中进行，镜头跟随角色并只呈现局部区域，不采用逐房间清怪和场景切换。战场使用策划设计的固定骨架来保证辨识度、美术质量和通行性，同时随机分布妖巢、事件、奖励与部分障碍物来提供局间变化。这样既能承载高密度妖群、自由走位与探索，也能保持“求生—成型—反压制”的连续压力；《元气骑士》只作为俯视角移动与美术表现的参考，不作为关卡结构参考。

战场尺度以移动时间而不是固定像素定义：主角以基础移速从一侧直线移动到另一侧约需四十五至五十秒。固定骨架划分为约 `7 × 7` 个逻辑区块，用来约束道路、障碍、危险地形、地标、事件点和敌人生成区；每局只随机激活和组合其中一部分内容。

## Consequences

- 敌人生成、地标和事件必须按连续世界坐标组织，并避免在玩家视野内突兀出现。
- 普通敌人主要从镜头外的生成环进入战场，不允许在玩家近处或当前视野中无预兆生成。
- 固定骨架必须提供经过验证的内容槽位和组合约束，随机系统只在这些合法范围内生成内容。
- 首发主线制作青石岭、沉星泽和烬沙古战场，分别承载炼气、筑基和结丹；各自的初、中、后期复用固定骨架，通过妖物、事件、环境危险和妖王内容产生变化。视觉色调依次从青绿土色过渡到蓝紫水雾，再到赤金与暗紫。
- 突破元婴后开放由既有战场与内容重组的无相妖域，不额外要求第四张主线地图。
- 战场边缘使用山壁、结界或深水等清晰的世界观表达和移动反馈，不能像尚未制作完成的空气墙；接触边缘本身不造成伤害。
- 战场不采用边缘环绕，主角不能从一侧越界后在另一侧出现。镜头到达世界边缘时停止移动，使地图界限保持可见。
- 战场不使用收缩区域或持续伤害强迫移动；限时事件、高价值奖励和精英目标通过更高收益吸引玩家探索，留守原地仍可生存但成长较慢。
- 主角没有默认复活；稀有战场事件可提供每局最多一张替劫符，在致命伤时恢复百分之三十最大生命、清除附近敌方弹道并给予两秒无伤，离开本局后不保留。
- 妖物掉落的灵蕴需要主角靠近拾取，玩家必须在清怪、走位和回收成长资源之间规划路线；灵蕴不能在击杀时直接自动结算。
- 移动端常驻小型雷达地图，显示战场边界、主角位置和已发现地标；限时事件同时提供雷达标记与屏幕边缘的方向、距离提示。普通妖物不显示，精英目标和妖王显示。
- 每局约在二分三十秒、五分三十秒和八分钟各出现一个不重复事件，玩家有四十五秒决定是否前往；五分三十秒的中期事件固定为灵泉涌现且不读取玩家当前生命，其余候选包括妖巢暴动、残阵修复和古修遗藏。
- 每局至少一个灵脉节点发生灵泉涌现。玩家在灵泉范围内累计引导约两秒，离开后进度暂停并缓慢衰减，受击不立即清空进度；完成后恢复约百分之三十五最大生命，并在约三十秒内扩大灵蕴拾取范围，每处灵泉只可完成一次。
- 灵泉涌现保留四十五秒供玩家决定是否完成；满生命完成时仍获得拾取范围增益，未使用的恢复量不能储存到之后。
- 事件出现时提前展示玩法类型和主要奖励；错过不施加惩罚，但玩家失去对应的灵蕴、灵石、推演或替劫符机会。
- 局内节奏主要由时间、空间分布和事件驱动，而不是开门进入下一个房间。
