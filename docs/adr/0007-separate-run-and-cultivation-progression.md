# 分离单局构筑与长期修行资源

法器、法器等级和灵蕴只服务当前一局并在结束后重置；探索与精英事件获得的灵石跨局保留，即使主角死亡也不扣除；只有击杀妖王才能获得用于突破境界的妖丹。这个选择让失败的一局仍有积累价值，同时保证境界推进必须通过完整通关，而不能只靠重复刷取普通妖物完成。

## Consequences

- 存档只保存灵石、妖丹、境界及其他明确的局外解锁，不能保存中断或失败局中的法器构筑。
- 失败结算必须清楚区分已保留的灵石与未获得的妖丹，避免玩家误以为资源被系统吞掉。
- 普通战斗与探索可以改善后续准备，但妖王胜利始终是长期进程的关键门槛。
- 境界突破以开放战场、剧情、术法和法器为主要回报，只附带小幅固定属性成长；永久数值不能取代局内构筑与走位能力。
- 首发主线包含炼气、筑基、结丹和元婴四个大境界，共十个节点；成功突破元婴即完成主线，元婴不再拆分初、中、后期。
- 普通玩家首次突破元婴的目标总时长为六至八小时，预计经历二十五至三十五次出战，其中十五至二十次成功击杀妖王；资源曲线不能靠无意义刷取延长这一时长。
- 九次境界推进各要求两场胜利：先完成一次标准历练，再完成一次带战场异变与强化妖王的进阶试炼；跨越大境界时使用专属破境试炼。共计十八场必要胜利，失败不会清除已经完成的历练。
- 当前节点的历练与试炼首胜各产出一枚对应妖丹，两枚在推进时自动消耗；失败不扣除已有妖丹，重复历练只产出灵石，不能刷取推进用妖丹。
- 境界推进只开放术法、法器和升阶配方的研习资格，玩家使用灵石决定解锁顺序；灵石不用于购买无限永久攻击力、生命，也不是出战消耗品。
- 术法是一次性横向解锁，学会后没有等级和重复强化；不同术法只能在用途与使用时机上形成选择，不能靠投入更多灵石成为数值必选项。
- 炼气初期默认掌握玄光护身诀，炼气中期开放惊鸿遁法的研习资格，筑基初期开放紫霄雷诀，结丹初期开放定妖真言；除默认术法外均需灵石学习。
- 炼气初期默认开放青锋剑匣、雷篆符册、四象阵旗与扶摇羽衣；筑基后可用灵石解锁照妖宝镜、缚灵索，结丹后可解锁镇岳玄印、御灵兽袋，使构筑复杂度随主线逐步展开。
- 一次标准胜利的灵石目标收益应足以解锁约一个同阶段内容；失败按存活时间、精英击杀和事件完成度结算，通常获得同阶段胜利收益的百分之三十五至七十。
- 更高境界战场提高灵石收益，但低境界战场仍需保留有意义的基础回报，不能沦为零收益内容。
- 法器、术法和进阶配方全部明码标价，由玩家指定解锁；灵石系统不使用抽卡、随机开箱或重复碎片。
- 境界条件决定当前可研习范围，灵石主要用于决定同阶段内容的解锁顺序；不得用高价制造连续十余局才能获得一个核心内容的强制刷取。
