# Ship an Installable, Progressively Cached PWA

## Context

镇妖十刻以移动浏览器为产品基准，且全部核心规则和存档都在客户端。可安装 PWA 能减少浏览器界面干扰并支持离线历练，但一次预缓存三张地图、全部音频和全部特效会显著增加首次访问成本。服务工作线程自动更新还可能在战斗中混用不同版本的代码与资产。

## Decision

首发支持安装为 PWA，并采用渐进式内容缓存。

- 提供 Web App Manifest、应用图标、启动表现和独立窗口模式。
- 首次访问缓存应用外壳、核心代码、公共音效和青石岭所需资源。
- 沉星泽与烬沙古战场在解锁或首次进入前按需下载；下载成功后加入离线缓存。
- 已下载内容在离线时允许历练、长期养成、断点恢复和存档导入导出。
- 离线时匿名统计可以跳过或在严格数量上限内短暂排队，绝不阻塞游戏。
- 检测到新版本时只在洞府提示更新，不在历练过程中刷新或替换运行代码。
- 应用更新前保存长期存档和历练断点；只有存档迁移验证成功后才启用新版本。
- 分享内容始终使用正式公开网址，而不是安装模式的内部导航地址。

## Consequences

- 首次进入成本集中在核心玩法和第一张战场，不需要预下载完整主线。
- 解锁新战场时需要明确显示下载大小、进度、失败与重试状态。
- 服务工作线程缓存必须按构建版本管理，并清理不再引用的旧资产。
- 自动化测试需要覆盖离线启动、更新等待、断点保存和存档迁移失败。
- 首次联网后从未下载过的地图不能离线进入，界面必须提前说明。
