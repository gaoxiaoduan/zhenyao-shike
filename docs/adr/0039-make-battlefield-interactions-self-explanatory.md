# 让战场交互自解释

战场事件与可交互物统一使用“身份、动作、进度、奖励”的信息结构，以玩家理解优先于完全不打断战斗。玩家首次遇到一种战场事件时暂停一次并简短说明名称、目标、期限和主要奖励；此后不再暂停，只保留方向、距离、进度与奖励提示。敌对可摧毁目标使用尖锐轮廓、破坏图标、实体形象、生命条与受击反馈；有益可引导目标使用圆润阵纹、交互图标与引导进度；纯地标只显示实体景物和名称；危险区域使用预警形状和时间变化。颜色只作为辅助，不能独自承担交互语义。

## Consequences

- 灵脉节点平时表现为石坛等实体地标，不显示暗示可互动的空白蓝圈；灵泉涌现发生后才出现青蓝引导区域、名称与恢复图标。
- 妖巢表现为可辨认的实体目标而不是红色圆形，所有攻击型法器都能将其作为合法目标；防御术法玄光护身诀不对妖巢造成伤害。
- 妖巢暴动出现后给玩家四十五秒决定是否前往；抵达后获得独立的六十秒战斗时限，需要摧毁妖巢并击杀守巢精英，超时则妖巢遁走且不施加额外惩罚。前往与战斗使用两个明确标示的计时阶段。完成奖励为四十灵蕴、一次额外推演，并在结算保留八枚灵石；运行时不得再把四十灵蕴重复拆成总价值一百二十。
- 每个事件必须在正常、静音、减少动态效果和不同色觉条件下仍能表达目标、状态与完成反馈。
