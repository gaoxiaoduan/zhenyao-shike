# Offer an Explicit Main-Campaign Assist Mode

## Context

主线需要同时服务追求构筑掌握感的玩家和主要想完成凡人修行故事的玩家。隐藏动态难度会让玩家无法判断构筑成长是否真实，也可能在表现良好时暗中惩罚玩家。

## Decision

- 默认使用固定、可重复验证的标准难度，不根据玩家表现暗中调整敌人。
- 主线设置中提供“从容历练”辅助选项，并在同一境界节点连续失败两次后温和提示，但不自动开启。
- 从容历练使玩家受到的伤害降低约百分之十五，并将危险预警时间延长约百分之二十。
- 辅助模式不改变敌人数量、敌人生命、掉落、法器候选、灵石、妖丹或镇妖刻印。
- 使用辅助模式可以正常完成全部主线并获得同等奖励，不标记低等结局。
- 无相妖域不使用从容历练，而通过公开、可选择的挑战异变控制难度。

## Consequences

- 所有平衡数据与匿名统计需要明确记录标准或从容模式，不能混合计算胜率。
- 敌人伤害与预警时长必须由集中规则调节，不能在各妖物实现中散落辅助判断。
- 设置文案应中性表达选择，不羞辱或劝退使用辅助模式的玩家。
- 标准难度仍需独立达到合理完成率，不能把辅助模式当作不平衡的补丁。
