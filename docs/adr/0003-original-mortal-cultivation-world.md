# 使用原创凡人流镇妖修仙世界观

游戏借鉴“凡人从弱小散修谨慎成长为高阶修士”的通用类型母题，但世界、组织、人物、剧情、法器和视觉符号必须原创。项目不使用《凡人修仙传》或其他既有作品的专有名称、可识别情节与设计，也不在产品名称、宣传或搜索投放中暗示授权、联动或其他特定联系；如未来获得正式授权，再通过新的决策重新划定边界。

## Consequences

- 内容设计应吸引喜欢资源经营、稳健求生和境界成长的“凡人流”受众，而不是依赖现有 IP 的认知。
- 每个核心人物、组织、地点和关键事件都需要具有独立来源与原创表达。
- 境界成长必须成为跨局长期目标，单局法器构筑则负责即时爽感，两者不能混为一套数值系统。
