# 将法器升阶作为构筑奖励

两件兼容基础法器均达到 Lv.5 后，玩家可在下一次升级界面主动执行升阶：消耗两件法器，获得一件不再升级的高阶法器，并释放一个法器槽。升阶使用固定且公开的两两配方，每件基础法器只对应少量兼容对象；升阶提示不占普通三选一位置，玩家可暂缓执行。每局最多持有两件高阶法器。这个设计将构筑规划的回报集中为明确的战力与视听跃迁，而不是让一次普通升级被合成操作挤占。

## Consequences

- 已持有且未满级的基础法器持续留在升级候选池中；若连续三次升级未出现，下一次必须出现，避免构筑因随机性无法成型。
- 高阶法器是完成态，后续升级选择会转而用于填补空槽或强化其他基础法器。
- 升阶界面必须预览消耗、结果、槽位变化与效果，且从获得基础法器时就展示其兼容对象，不能让玩家盲猜配方。
- 升阶结果需要逐个设计并测试，不允许通过“任意两件法器都能合成”的规则批量生成缺乏辨识度的结果。
- 首个可发布版本包含八件基础法器与八件高阶法器；每件基础法器对应两个兼容对象，以有限内容形成可规划的配方网络。
- 妖王按“一件高阶法器加三件较高等级基础法器”作为正常成型基准；两件高阶法器是高效率探索与正确构筑带来的优势，不是通关前置条件。
- 两件高阶法器的上限是性能、可读性与数值平衡的硬约束；若要提高上限，必须重新评估战斗密度与移动端表现。
