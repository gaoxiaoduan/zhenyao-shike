# 让妖王拥有独立决战阶段

生存与成长阶段结束后停止普通妖群生成，并用约三秒的天地异变与危险预警进入妖王战；场上残余普通妖物被妖王吞噬或召回。妖王战只生成该妖王专属设计的少量召唤物，不继续叠加普通无限妖潮，也不设置硬倒计时，目标战斗时长为六十至一百二十秒。这个选择以清晰预警、可读走位和高潮感优先于全程不断流的敌群压力。

## Consequences

- 每名妖王需要专属召唤物、招式节奏和转场表现，不能只是拥有高生命值的普通敌人。
- 三张主线战场各设计两名妖王，共六名；妖王随境界节点逐步解锁新招式，试炼版本必须拥有完整第二阶段，不能只提高生命与伤害。
- 首发妖王为青石岭的啸月狼王、盘根槐母，沉星泽的吞雾蟾君、玄鳞泽蛟，以及烬沙古战场的烬羽沙鸮、万兵妖主；万兵妖主承担元婴破境终战。
- 妖王转场时，战场上所有未拾取灵蕴自动飞向主角；由此触发的升级选择和升阶在完全暂停状态下依次结算，全部完成后妖王才开始行动。
- 残余妖物、弹道与其他掉落物必须按明确规则结算，避免转场制造不透明损失。
- 妖王战的胜负由击杀或主角死亡决定，战斗时长是调优目标而非强制计时规则。
