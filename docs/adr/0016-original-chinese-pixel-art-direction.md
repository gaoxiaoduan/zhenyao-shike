# Use an Original Chinese Pixel-Art Direction

## Context

镇妖十刻借鉴俯视角像素动作游戏的移动与表现形式，但世界观、角色、妖物、法器和界面都需要建立独立辨识度。战斗同时包含大量敌人和特效，氛围不能压过危险预警与单位辨识。

## Decision

采用“国风低分彩色像素 + 清晰现代 UI”的原创美术方向。

- 战场、角色和妖物采用原创俯视角像素美术，优先保证剪影、阵营和危险程度可识别。
- 不复刻其他游戏的角色比例、场景素材、动画、配色方案或界面布局。
- 青石岭以青绿和土黄为主；沉星泽以幽蓝、紫和灰为主；烬沙古战场以赤金和暗紫为主。
- 法器表现使用剑气、雷篆、阵纹、玄印、宝镜和灵契等原创国风视觉语言。
- 高阶法器必须拥有明显的形态、音画和攻击节奏变化，而不只是增加数值。
- 战斗区域保持像素质感；Vue 产品界面使用清晰的现代中文字体与轻量卷轴纹理，不使用低分辨率像素字体承载长文本。
- 危险招式使用跨地图一致的高对比预警语言，不因水墨、雾气或环境色而降低可读性。
- 主角首发制作四方向待机、移动和施法动画，以及通用受击与倒地动画；通过衣摆延迟、脚步扬尘、停步回弹和随实际移速变化的步频表达移动手感，不制作完整八方向动画集，也不为重量感加入影响躲避响应的规则惯性。
- 主角以朴素短打、采药囊、绑腿和十刻镇妖盘形成凡人散修剪影，不手持代表固定修行流派的主武器；剑、符、阵等战斗身份由本局法器构筑在角色周围呈现。
- 每种术法至少拥有施放、持续和结算三层可辨识表现。青石岭切片先完整制作玄光护身诀：主角结印、玄光符纹展开、与震退范围一致的冲击波、持续护体纹样、挡格涟漪和结束收束；其余术法在玩法实现时达到同一质量线，不提前制作无规则支撑的表现空壳。
- 术法采用局部华丽、全局克制的表现强度，不能遮住敌方投射物和妖王预警；减少动态效果时保留规则边界、状态和命中反馈，关闭震屏、强闪光与大部分残影。
- 主角进入普通受击保护时短暂显示高亮描边与衣物闪白，不通过整个人透明闪烁表达；普通攻击命中保护状态时使用小型散射效果与轻量音效说明伤害未重复结算。
- 桌面与移动端共享正式术法图标、径向冷却遮罩、剩余秒数、护盾持续时间环和可施放状态；移动端不能以纯文字按钮替代术法视觉身份。减少动态效果时使用静态高亮替代脉冲。

## Consequences

- 美术验收需要同时检查氛围、原创性和战斗缩放下的轮廓辨识。
- 三张地图可以共享技术管线，但必须通过色盘、地表、障碍和环境效果形成明显差异。
- Vue 界面与 Phaser 战场可以采用不同的文字与渲染策略，但需要共享颜色和图标语义。
- 高阶法器需要单独的表现预算，不能只复用基础法器并放大特效。
